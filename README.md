Варіант: $N = 25, K = 19, a = 1, b = 1, c = 0$
1. Розрахунок параметрів варіанта
2. $N = 25$ (номер у списку)$K = 19$ (перша літера імені «О» — Олександр, 19-та літера в абетці)
3. $a = N \bmod 3 = 25 \bmod 3 = 1$ $\rightarrow$
4.Завдання 2: Обчислити кількість елементів масиву, більших за $K \bmod 10 = 19 \bmod 10 = 9$.$b = N \bmod 4 = 25 \bmod 4 = 1$ $\rightarrow$ Завдання 1: Обчислити максимальну глибину вкладеності папок.
5.c = N \bmod 5 = 25 \bmod 5 = 0$ $\rightarrow$ Завдання 3: Перебрати усі перестановки перших $M = (19 \bmod 3) + 3 = 1 + 3 = 4$ літер імені (ОЛЕК).
Базові випадки рекурсивних функцій
Завдання 1 (Обхід каталогів): Базовим випадком є досягнення каталогу, який не містить жодної вкладеної папки (масив підкаталогів порожній), через що цикл перебору підпапок не виконується і функція повертає базову глибину 1.
Завдання 2 (Розбиття навпіл): Базовим випадком є відрізок масиву розміром в один елемент (lo == hi), де обчислюється умова a[lo] > 9.
Завдання 3 (Перебір з поверненням): Базовим випадком є момент, коли довжина сформованого списку символів дорівнює загальній кількості літер (current.Count == items.Length), після чого виводиться сформована перестановка.
